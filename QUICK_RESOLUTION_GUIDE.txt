## THE 4-LOCATION CHECKLIST FOR RESOLUTION CHANGES

Edit only these 4 lines in `app/MAIN_FILE_SINGLE_CAM.py` to change resolution:

### Location 1: Lines 1350-1356 (Options Dictionary)
```python
self.frame_ratio_options = {
    "640x480": (640, 480),
    "800x600": (800, 600),
    "1024x768": (1024, 768),
    "1280x720": (1280, 720),  # ← Add/remove resolutions here
}
```

### Location 2: Line 1357 (Default Setting)
```python
self.frame_ratio_setting = "1280x720"  # ← Change to desired resolution
```

### Location 3: Line 1358 (Width)
```python
self.frame_width = 1280  # ← Match width from options dict
```

### Location 4: Line 1359 (Height)
```python
self.frame_height = 720  # ← Match height from options dict
```

## HOW TO TEST A RESOLUTION CHANGE

1. Find what resolution your camera supports: `python camera_diagnostic.py`
2. Edit the 4 lines above to use a supported resolution
3. Restart app
4. Verify HUD shows correct resolution in bottom-left corner
5. Check frame fills entire viewing area (no black borders)

---

## WHAT TO DO IF THINGS BREAK

1. Check terminal for `[CAMERA]` messages showing actual resolution
2. Run diagnostic tool: `python camera_diagnostic.py`
3. Only use resolutions marked "✓ SUPPORTED"
4. Make sure all 4 locations above have matching values
5. Restart app completely
