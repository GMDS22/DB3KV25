POSSIBLE CAUSES (in order of likelihood):
==========================================

1. SERVO POWER ISSUE (Most likely)
   - Check if servo power LED is ON (red light)
   - Measure voltage with multimeter (should be 6-8.4V DC)
   - Check power wire connections (red wire)

2. SERVO NOT CONNECTED TO DEBUG BOARD
   - Check signal wire (yellow/white) from Debug Board to servo
   - Check ground connection (black wire)
   - All three wires (signal, power, ground) must be secure

3. SERVO FIRMWARE CHANGED
   - Servo IDs may have been reprogrammed
   - Servo protocol may be different than expected
   - Need to use servo.exe to verify current configuration

4. DEBUG BOARD FIRMWARE ISSUE
   - Debug Board firmware might not match current implementation
   - Or it's a different model than expected
   - Need to test with servo.exe

5. WIRING DAMAGE
   - Check for broken connections
   - Check for corrosion on connectors
   - Try different servo wires
